# SEO Research Method v0.1

> 狀態：Research Baseline  
> 目的：先保存目前研究出的可重複方法，後續持續用更多文章與網站樣本迭代。

## 1. 基本原則

SEO 研究不把「排名靠前」簡化成單一固定文章格式。

目前採用的判斷方式是：

- 觀察排名文章與成熟網站的共同 Pattern
- 區分 Search Intent
- 區分跨產業共通結構與產業特例
- 研究 Keyword / Long-tail / Topic Cluster / Content Gap
- 研究文章結構，但不盲目複製其事實品質、來源品質或品牌偏見

## 2. Keyword Research Flow

```text
核心 Keyword
→ 同義搜尋語言
→ Search Intent
→ Related Questions
→ Decision Factors
→ Long-tail Keywords
→ Topic Cluster
→ SERP / Competitor Review
→ Content Gap
→ Article Title Candidates
```

## 3. Search Intent 類型

目前至少區分：

- Informational
- Comparison
- How-to
- Selection Guide
- Commercial Investigation
- FAQ / Problem Solving
- Policy / Regulation
- Cost / Eligibility

文章結構必須由 Search Intent 決定，不採單一固定模板。

## 4. 第一輪共同 Pattern

### 4.1 Primary Keyword 靠近標題前段

標題優先採：

```text
Primary Keyword + 明確價值 / 問題 / 結果
```

### 4.2 開頭快速回答

避免長篇空泛背景。

建議：

```text
H1
→ Direct Answer / Summary
→ 本文會解決什麼
→ 正文
```

### 4.3 一個 Keyword 要拆成一組子問題

不要機械重複 Keyword。

應拆：

- 核心概念
- Decision Factors
- Related Questions
- Common Problems
- Long-tail Questions

### 4.4 比較型 Query 優先用表格

適用：

- 材質比較
- 費用比較
- 資格比較
- 方案比較
- 規格比較

### 4.5 Objection Coverage

正文要主動回答：

- 缺點
- 風險
- 常見錯誤
- 迷思
- 使用者疑慮
- FAQ

### 4.6 Evidence

對可驗證資訊，優先引用：

1. 官方來源
2. 法規
3. 政府統計
4. 原始研究 / 一手資料
5. 專業機構
6. 高品質產業來源

競品文章可以拿來研究 SEO 結構，但不應自動視為事實依據。

### 4.7 更新資訊

對法規、薪資、費用、資格、政策類文章，應明確標示：

- 首次發布日期
- 最後更新日期
- 本次更新內容

禁止只改日期製造「最新」假象。

## 5. 目前文章結構框架

```text
1. Primary Keyword
2. Search Intent
3. User Question
4. Direct Answer

5. Topic Breakdown
   ├─ Core concepts
   ├─ Decision factors
   ├─ Related questions
   └─ Long-tail questions

6. Main Content
   ├─ H2
   ├─ H3
   ├─ Tables where useful
   └─ Steps where useful

7. Objection Coverage
   ├─ Problems
   ├─ Risks
   ├─ Mistakes
   ├─ Myths
   └─ FAQ

8. Evidence
9. Practical Conclusion
10. Related internal content
```

## 6. 不要直接照抄的東西

- 不明來源的精確數字
- 品牌自我比較當成客觀證據
- 沒有來源的「專家說」
- 過度聳動標題
- Keyword Stuffing
- 為了 SEO 犧牲可讀性
- 一般網站互相引用，卻沒有原始來源
