# SEO Article Research

這個 repository 用來保存 SEO 關鍵詞研究、文章結構研究、文章輸出格式與後續 Skill 方法論。

## 目前狀態

目前先以 **Research / Method v0.x** 方式累積，不急著定義正式 v1.0。

## 研究方向

1. Keyword Research
   - 核心關鍵詞
   - 長尾關鍵詞
   - Search Intent
   - Topic Cluster
   - Content Gap
   - 標題 Pattern

2. SEO Writing
   - 文章結構
   - H2 / H3
   - Direct Answer
   - 比較表
   - FAQ / Objection Coverage
   - 來源與 Evidence
   - 內部連結
   - 更新資訊

3. CMS-ready Article Output
   - Markdown 內文
   - 摘要
   - Tags
   - SEO Title
   - Meta Description
   - Cover image
   - Inline images
   - Alt text
   - Image generation prompts
